# **App Name**: Contextual Insights

## Core Features:

- User Authentication: Secure user authentication with email/password and Google OAuth.
- Dashboard: Dashboard to initiate new research queries and view recent results.
- Detailed Result View: Display of AI-generated research results with title, introduction, key insights, conclusion, and sources, along with bookmark functionality.
- AI Research Generation: AI-powered summarization and key insight extraction from user-provided text, URLs, and YouTube links, generating a structured JSON output using Gemini API or GPT-4 as a tool.
- User Profile: Profile page to manage user information, view research history, and set preferences.
- Settings Page: Settings page with options for dark mode, API key integration, and other preferences.
- AI Feedback Mechanism: Allow users to provide a rating for AI responses to collect user feedback.

## Style Guidelines:

- Primary color: HSL 210, 67%, 47% (Hex: #2E86C1), a calming and professional blue, suggesting clarity and insight.
- Background color: HSL 210, 20%, 95% (Hex: #F0F4F8), a very light, desaturated blue for a clean, non-distracting background.
- Accent color: HSL 180, 54%, 40% (Hex: #3EB489), a vibrant teal to highlight key actions and elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif for a modern, machined, objective look. This font will be used for both headlines and body text.
- Code font: 'Source Code Pro', a monospaced sans-serif suitable for computer code display.
- Modern & Minimalist Design: Clean aesthetics, ample whitespace, subtle shadows, rounded corners throughout.
- Subtle transitions on hover, focus, and state changes for a polished feel (e.g., button presses, card expands).
